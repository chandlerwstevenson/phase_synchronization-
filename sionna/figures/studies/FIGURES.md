# Figure catalog

All figures live in `figures/studies/`. Every figure was rendered with
plain default matplotlib (default color cycle, default fonts, nothing
custom beyond figure size and resolution) and contains no text inside
the plotting area — only data, axes labels with units, legends, and
neutral titles. Identification labels on the scene/deployment maps
(station indices, target names) are the one exception.

Every simulation behind every figure was re-run fresh on 2026-08-15
(no cached results were read; caches were regenerated by the runs).
Fresh-run agreement with previously recorded values is noted per
family below. Generating scripts are the `fig_*.py` files in this
directory; each saves its data as JSON alongside the PNGs so figures
can be re-rendered without re-simulating.

Terms: "beam quality" = coherent array gain relative to a perfectly
synchronized array; "detection" = counted probability of detecting the
target in Monte-Carlo trials; "net throughput" = communication rate ×
the fraction of airtime not spent synchronizing.
